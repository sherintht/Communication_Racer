# COMMUNICATION RACER 2026

Department Association gamified Communication Systems activity.

## Included
- 100-question race: 25 questions x 4 modules
- Optional 15/20/30 minute timer or practice mode
- Player database stored in browser localStorage
- Leaderboard
- Lives, streaks, score, badges and checkpoints
- Sound effects generated by Web Audio API (no external audio files required)
- Responsive UI
- CO metadata on every question

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For the best experience, use VS Code Live Server or:
   `python -m http.server 8080`
4. Open `http://localhost:8080`

## Important database note
This version stores player/result records in the browser's localStorage. It is suitable for a single PC/classroom station. It is NOT a central multi-computer database.

For a department-wide event where many PCs/phones submit to one central database, connect the same frontend to Supabase/Firebase or a small FastAPI + SQLite/PostgreSQL backend.

## Replace questions
Edit `questions.js`. Each item has:
- module
- moduleName
- question
- options
- answer
- difficulty
- co

The included questions are a starter bank and should be checked against the final approved syllabus before the event.

## Suggested championship rule
15 minutes, 100 questions, minimum 50/100 to qualify. You can change the rule in the UI/event notice.


## Google Sheets connection

The game supports a central Google Sheet result database.

### Best setup
Use your existing Google Sheet as the central event database. Add the Apps Script code from `GOOGLE_SHEETS_SETUP.gs` using **Extensions -> Apps Script**. Deploy it as a Web App, then paste its URL into:

`const GOOGLE_SHEET_WEBAPP_URL='YOUR_WEB_APP_URL';`

in `game.js`.

Each completed game sends:
- Timestamp
- Name
- Roll number
- Class
- Mode
- Score / 100
- Game points
- Accuracy
- Completion time
- Qualification
- Module 1–4 scores

### Question bank
The included `questions.js` contains 100 starter questions (25 per module). Before the official event, verify them against the final approved syllabus. You can also move the question bank into Google Sheets later so that the teacher can edit questions without changing the code.

### Learning vs Championship
**Learning Mode:** unlimited time; intended for repeated practice and learning.

**Championship Mode:** 15 minutes; intended for the official competition. The timer is explicitly displayed before the student starts.

This design deliberately does not make the learning experience time-limited.
