# PREMIUM UI CHANGE

This version intentionally changes the visual hierarchy:
- Full-screen start-line experience instead of a dashboard-heavy landing page.
- Road dominates the gameplay screen.
- Question is a compact race HUD at the bottom, not a large card covering the highway.
- Player bike is CSS-rendered; traffic vehicles are CSS-rendered to avoid blue emoji squares.
- Correct answers are the accelerator; wrong answers slow the race.
- Four-lane steering remains active.
- Learning and Championship modes remain separate.


## ONE-CLICK RACE FLOW
The registration/check-in is now the only pre-race screen. After the student enters name/roll and chooses Learning or Championship, START RACE NOW loads the highway directly. The old separate map screen is hidden from the normal flow.
