# COMMUNICATION RACER 2026 — ACADEMIC QUESTION MAP

Source: S5 Analog and Digital Communication, Course Code 24SPJPECT502.

The uploaded syllabus has four modules:
1. Analog communication — CO1
2. Digital communication — CO2
3. Baseband transmission through AWGN — CO3
4. Digital modulation — CO4

The question bank contains exactly 25 questions per module (100 total).
Each question includes Module, CO, Topic, Difficulty, Answer and Explanation.

Module 1 topics used:
Communication-system block diagram, need for modulation, AM equation/spectrum, DSB-SC, SSB, pilot carrier, VSB, FM/PM, Carson's rule, pre-emphasis/de-emphasis, AM vs FM, FM receiver, superheterodyne receiver and image frequency.

Module 2 topics used:
Sampling, Nyquist rate, aliasing, anti-aliasing, quantization, SQNR, PCM transmitter/receiver, companding, μ-law, DPCM, delta modulation, slope overload, granular noise, adaptive delta modulation and line codes.

Module 3 topics used:
AWGN, ISI, Nyquist zero-ISI criterion, raised-cosine spectrum, roll-off factor, equalization, zero-forcing equalizer, Gram-Schmidt, signal space, vector AWGN model, matched filter, correlation receiver, MAP receiver, ML receiver and eye diagram.

Module 4 topics used:
BPSK, BPSK constellation/transmitter/receiver, BER vs SNR, QPSK, QPSK bits/symbol, I/Q, QPSK transmitter/receiver, QAM, QAM constellation, Gray coding, Euclidean separation and modulation selection.
